# Отчёт по экспериментам: диагностика mimic-video и стратегии inference

> Этот исторический отчёт описывает раннюю LIBERO-диагностику. Сводка новых
> MIMIC-Video и GR00T N1.7 прогонов на SIMPLER, INT-ACT, LIBERO-Pro,
> LIBERO-Plus и обычном LIBERO Spatial, включая 95% Wilson CI, поддерживается в
> [RESULTS.md](RESULTS.md).

Документ описывает проведённые исследования на базе предобученной **mimic-video** (Video2World + World2Action) в среде **LIBERO Spatial**: сбор диагностических метрик, статистический анализ различий success/failure, обучение CatBoost-классификаторов и три стратегии адаптивного inference при rollout.

---

## 1. Модель

Использовалась публичная **mimic-video** — Video-Action Model на основе Cosmos-Predict2:

- **Video2World** генерирует латентное представление будущего видеоконтекста по текущему наблюдению и языковой инструкции.
- **World2Action** декодирует из этого контекста чанк действий размерности `(60, 10)` (60 шагов при 20 Hz: Δпозиция, rotation 6D, gripper).
- На rollout в LIBERO действия приводятся к 7D (Δpos + rotvec + gripper) для контроллера OSC_POSE.

Один запрос к модели = один **chunk**; `seed` задаёт начальный шум diffusion и влияет на вариативность кандидатов при повторной генерации.

Подробнее об архитектуре и пайплайнах: [MODEL.md](../MODEL.md).

## 3. Анализ метрик: различие распределений success и failure

При eval включено **покадровое trace-логирование** без усреднения метрик на уровне эпизода (см. [METRICS.md](METRICS.md)):

- **chunk-метрики** — один вектор на каждый inference-chunk (латенты видео, ошибка flow, план-дрифт, энтропия действий и т.д.);
- **action-метрики** — одна строка на каждое исполненное действие внутри чанка.

Подробно (структура файлов, источники и формулы для метрик из действий, логика candidate-логирования для `catboost_select`):  
см. [METRICS_DETAILS.md](METRICS_DETAILS.md).

### 3.1. Тест Колмогорова–Смирнова (KS)

Для каждой пары *(метрика, chunk_id)* сравнивались эмпирические распределения значений на **успешных** (69 эпизодов) и **неуспешных** (31 эпизод, timeout) rollout-ах двусторонним **two-sample KS test** (`scipy.stats.ks_2samp`).

- Всего пар (metric × chunk_id): **936**
- Значимых при **p < 0.05**: **475** (~51%)

Полные таблицы: `eval_outputs/libero_spatial/baseline/trace_100ep/metrics/chunk_ks_analysis/`.  
Сводный markdown: `chunk_metric_ks_significant_summary.md`.

**Интерпретация KS:** статистика KS измеряет максимальное расхождение между эмпирическими CDF двух выборок; малый p-value означает, что гипотеза «распределения одинаковы» отвергается — метрика систематически различается между success и failure на данном номере чанка.

### 3.2. Метрики с наиболее выраженным разделением

Ниже — метрики, которые **стабильно** входят в топ по KS-статистике на ранних и средних chunk_id (типичные p-value порядка 10⁻⁹–10⁻⁵, KS ≈ 0.45–0.71). На failure-эпизодах, как правило, выше ошибка предсказания, дрифт плана и вариативность действий.

| Метрика | Смысл (кратко) |
|---------|----------------|
| **chunk_action_delta_norm_mean** | Средняя «резкость» изменения действий внутри чанка; на failure чаще выше — менее плавные, рывкообразные команды. |
| **flow_prediction_error** | Ошибка flow-matching / предсказания динамики в латентном пространстве; рост сигнализирует о несогласованности модели с фактической динамикой сцены. |
| **plan_drift** | Накопленное расхождение плана (латент/траектория) от ожидаемого направления к цели. |
| **action_chunk_temporal_consistency** | Согласованность действий во времени внутри чанка; на failure обычно **ниже** (противоположный знак сдвига средних). |
| **action_entropy** | Энтропия распределения действий в чанке; выше на неуспешных траекториях — больше неопределённости политики. |
| **video_action_mutual_information** | Связь между видео-латентом и действиями; на failure часто **ниже** — слабее согласование «что вижу» и «что делаю». |
| **mlp_activation_mean** | Средняя активация скрытых слоёв декодера; отражает «режим» сети при генерации. |
| **task_semantic_alignment** | Согласованность представления с языковой инструкцией. |
| **video_latent_variance_mean** | Дисперсия видео-латента — нестабильность визуального предсказания. |
| **representation_drift_rate** | Скорость дрифта представления между шагами. |
| **decoder_hidden_norm_mean / std** | Нормы скрытых состояний action-декодера. |
| **object_interaction_confidence** | Условная «уверенность» во взаимодействии с объектом. |
| **sampling_stability** | Стабильность сэмплирования diffusion при фиксированном контексте. |
| **goal_latent_distance** | Расстояние в латенте до целевого состояния. |

Эти и родственные признаки (всего **36** chunk-признаков без `chunk_id`) вошли в обучение **chunk-level CatBoost**.

### 3.3. Jensen–Shannon divergence (JSD)

Дополнительно для тех же пар (metric, chunk_id) считалась **JSD** (база 2) между гистограммами success/failure — мера «перекрытия» распределений, удобная для ранжирования метрик внутри каждого chunk_id.

Артефакты: `metrics/chunk_jsd_analysis/`, графики: `metrics/chunk_distribution_plots/`.

Пересчёт KS:

```bash
python scripts/analysis/compute_chunk_metric_ks.py
```

## 4. Обучение CatBoost-классификаторов

На базе trace-логов базового прогона (100 эпизодов) построен **фиксированный split 70 train / 30 validation** (`episode_split_70_30.json`): в validation — **20 success + 10 failure**, с покрытием всех 10 задач.

### 4.1. Chunk-level CatBoost

- **Цель:** предсказать P(failure) для **целого чанка** по 36 диагностическим признакам.
- **Обучение:** только train-эпизоды (70).
- **Метрики на validation (chunks):** ROC-AUC ≈ **0.74**, average precision ≈ 0.62 при пороге 0.5.
- **Модель:** `artifacts/libero_spatial/v2/catboost_chunk_regen.cbm`

Скрипт: `scripts/training/build_episode_split_and_train_catboost.py`.

### 4.2. Action-level CatBoost

- **Цель:** для **отдельного шага** внутри чанка оценить P(failure) по 7 action-признакам (нормы, gripper, offset в чанке и т.д.).
- **Применение:** динамический горизонт исполнения — сколько действий из чанка выполнять до следующего запроса к модели.
- **Метрики на validation:** ROC-AUC ≈ **0.75**; рекомендованный порог success ≈ **0.46** (`recommended_action_success_threshold.txt`).
- **Модель:** `artifacts/libero_spatial/v2/catboost_action_regen.cbm`

Скрипт: `scripts/training/train_action_regeneration_classifier.py`.

## 5. Стратегии inference при rollout

Реализованы в `eval/libero/run.py` (`--regen_strategy`). Ниже — три исследуемые стратегии, использующие обученные CatBoost.

### Стратегия 1: выбор из 3 кандидатов (`catboost_select`)

1. Для одного запроса генерируются **3 чанка** с разными `seed`.
2. Chunk CatBoost оценивает P(failure) для каждого.
3. В среду отдаётся чанк с **минимальной** P(failure).

Смысл: дешёвая диверсификация через стохастичность diffusion без полного перезапуска эпизода.

### Стратегия 2: динамический горизонт действий (`action_dynamic`)

1. Генерируется один чанк.
2. Action CatBoost оценивает уверенность по шагам; выполняется только префикс из **3–8** действий (параметры `action_min_execute_actions`, `action_max_execute_actions`), затем новый запрос к модели.

Смысл: чаще пересчитывать политику, когда внутри чанка падает предсказанная «успешность» шагов.

### Стратегия 3: гибрид (`hybrid_select_action_dynamic`)

1. Сначала **стратегия 1** (выбор лучшего из 3 чанков).
2. Затем **стратегия 2** на выбранном чанке (динамический горизонт).

Смысл: совместить отбор качественного чанка и осторожное пошаговое исполнение.

### Результаты на validation-наборе (30 эпизодов)

Оценка проводилась на **фиксированном validation split** (те же 30 эпизодов, что при обучении классификаторов; повторный rollout со стратегиями, а не только классификация сохранённых логов).

| Режим | Success rate |
|-------|----------------|
| **Базовый mimic-video** (без regen-стратегий) | **0.6667** (20/30) |
| **Стратегия 1** — `catboost_select` (3 кандидата) | **0.6667** |
| **Стратегия 2** — `action_dynamic` | **0.70** |
| **Стратегия 3** — `hybrid_select_action_dynamic` | **0.70** |

Для сравнения, на **полном** бенчмарке 100 эпизодов базовый прогон дал **69/100 (69%)** success без дополнительных стратегий.

**Вывод:** пока что все три подхода особо не улучшают validation success относительно baseline; Быстрее всего это связано с моделю для оценки сгенерированных чанков, для ее улучшения нужно собрать больший и более грамотный датасет для обучения.

---

## 6. Выводы

1. Диагностические метки модели **систематически различают** success и failure; KS выделяет прежде всего динамику действий, ошибку flow, plan drift и согласованность video–action.
2. CatBoost на chunk- и action-признаках даёт умеренно хорошее ранжирование (AUC ~0.74–0.75) и пригоден как **сигнал для inference-time решений**, а не только для постфактум анализа.
3. **Inference-time вмешательство**  измеримый прирост на validation без дообучения основной VAM пока, что получить не получилось.

---

## 7. Дальнейшие направления

1. **Расширение и качество датасета для обучения**  
   Собрать больше rollout-ов (другие задачи LIBERO, больше эпизодов на задачу, разнообразие начальных состояний), сбалансировать failure/success и более грамотная разметка действий. Это повысит надёжность CatBoost и порогов.

2. **Голова уверенности в самой модели**  
   Дообучить отдельную **голову предсказания confidence / success** поверх frozen Video2World + частично World2Action, чтобы сигнал неуспеха шёл из представления модели end-to-end, а не только из handcrafted метрик.

3. **Совместная оптимизация стратегий**  
   Подбор порогов action CatBoost, числа кандидатов и горизонта execute на полном val/full bench; возможно обучение лёгкого policy поверх метрик для decide «regen / continue».

4. **Масштабирование оценки**  
   Подтвердить val-результаты на полных 100 эпизодах с фиксированными seed и отчётностью по задачам.
